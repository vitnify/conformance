# Receipt vectors

Static, language-agnostic receipt vectors — the frozen wire bytes a conformant
verifier is measured against. Each `*.json` here is one case; [`index.json`](index.json)
is the manifest. Generated by [`tools/gen_receipt_vectors.py`](../../tools/gen_receipt_vectors.py);
these committed files, not the generator, are the corpus.

## Schema

```jsonc
{
  "id": "R08",                        // stable case id (R* must reject, A* must accept)
  "description": "reject: tampered chain pointer",
  "expect": {
    "ok": false,                      // the verdict a conformant verifier MUST return
    "flags": { "containment_enforced": false }   // optional: exact checks it must also report
  },
  "verify_kwargs": {                  // verifier options for this case (JSON-native)
    "pinned_pubkeys": ["<hex ed25519>"]
  },
  "certificate": { ... },             // the signed vitnify-receipt, all wire fields
  "log": [ { "i", "kind", "payload", "prev" }, ... ]   // the event log, in order
}
```

- **`certificate`** is the receipt exactly as serialized: `v`, `program_hash`,
  `capabilities`, `event_root`, `n_events`, `head_hash`, `model_digests`, `issued_at`,
  `nonce`, `run_id`, `sig`, `sig_alg`, `pubkey`. A verifier reconstructs the signed
  body **from the receipt's own `v`** (v1 omits `issued_at`/`nonce`/`run_id`), so a v1
  receipt still verifies under a v2 verifier.
- **`log`** is the ordered event list. Each event's `canonical()` form
  (`{"i","kind","payload","prev"}`, BLAKE3) is what the Merkle root and head hash are
  recomputed from — reorder, edit, or drop one and the root no longer matches.
- **`expect.flags`** names checks the verdict must also report exactly (e.g. an
  observe-only receipt is `ok=true` but `containment_enforced=false`).

## Testing a verifier in another language

1. For each entry in `index.json`, load its file.
2. Reconstruct a certificate and event log from `certificate` / `log`, using **BLAKE3**
   and reconstructing the signed body per the receipt's `v`.
3. Verify (honoring `verify_kwargs`).
4. Assert the verdict equals `expect.ok` and every `expect.flags` entry matches.

Conformant iff every case matches. The Python reference does exactly this in
[`conformance/adapters/vitnify_py.py`](../../conformance/adapters/vitnify_py.py).
The normative field semantics are in the
[vitnify-receipt spec](https://github.com/vitnify/vitnify-receipt-spec).
